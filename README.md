# Bridwell Limited

The website for Bridwell Limited, Kerala. Crop protection, plant nutrition,
and soil health products.

Plain HTML, CSS and vanilla JavaScript. No build step, no dependencies.
`index.html` plus `assets/`. Open `index.html` in a browser to preview the
still version; serve the folder over HTTP for the full scroll video.

## Swapping in real photographs later

Replace these files in `assets/` and nothing else has to change. Keep the same
filenames and roughly the same shape (landscape, about 1920px wide).

| File | Shows |
|---|---|
| `section-protection.jpg` | Crop protection card |
| `section-nutrition.jpg` | Plant nutrition card |
| `section-soil.jpg` | Soil health card |
| `section-field.jpg` | Full width field band |
| `section-dealers.jpg` | Dealers section |

The two product bottles are Bridwell's own packaging and do not need replacing.
